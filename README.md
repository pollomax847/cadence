> **[Français](README.fr.md)** | English

Self-hosted audio library management tool: auto-rename files via Shazam, sync metadata from Plex, organize folders in Lidarr format — all from a web dashboard.

---

## Features

- **Web dashboard** — launch and monitor jobs from a browser (Flask + HTMX)
- **Auto-rename via Shazam** — identifies audio files and renames them `Artist - Title.mp3`
- **AcoustID fallback** — when Shazam fails, queries MusicBrainz via audio fingerprint
- **Plex metadata sync** — writes corrected tags (title, artist, album, year, genre) from your Plex library back to files
- **Lidarr-style organization** — moves files into `Artist/Album (Year)/01 - Artist - Album - Title.ext`
- **iTunes integration** — reads your Apple Music/iTunes library
- **mergerfs & multi-disk** — supports pooled or individual disk mounts
- **Bogus tag detection** — ignores placeholder tags (`-Artist-`, `-Title-`, `Unknown`) and forces Shazam recognition

## Quick Start

**Requirements:** [Docker](https://docs.docker.com/engine/install/) with Compose v2

```bash
git clone https://github.com/pollomax847/cadence.git
cd cadence
./setup.sh
```

The setup wizard asks a few questions (music folder, Plex token, disk layout) and generates `.env` + `docker-compose.override.yml` automatically. No YAML editing required.

After setup:
```
Web UI → http://localhost:8900
```

## AcoustID (optional)

For the MusicBrainz fallback when Shazam fails, get a free API key at [acoustid.org/new-application](https://acoustid.org/new-application) and enter it during setup.

## Docker Commands

```bash
# Start web UI
docker compose up -d webui

# Stop
docker compose down

# Run a one-shot script
docker compose run --rm scripts run python3 playlists/write_tags.py --all --apply

# Rebuild after code changes
docker compose build && docker compose up -d webui
```

## Configuration Reference

Key variables in `.env` (generated by `setup.sh`):

| Variable | Description |
|---|---|
| `MUSIC_HOST` | Path to your music library |
| `PLEX_TOKEN` | Plex authentication token |
| `PLEX_URL` | Plex server URL |
| `ACOUSTID_API_KEY` | AcoustID API key (free) |
| `WEBUI_PORT` | Web UI port (default: 8900) |
| `AUDIO_SCRIPTS_HOST` | Path to audio scripts folder |
| `MUSIC_SORT_HOST` | Path to Lidarr sort script folder |

## Troubleshooting

**Shazam not recognizing files in batch?**
Normal — Shazam rate-limits bulk requests. Cadence applies an adaptive delay (1s on success, 4s on failure) and falls back to AcoustID automatically.

**Files renamed to garbage (`-Artist- - -Title-.mp3`)?**
Fixed in this version — bogus placeholder tags are now detected and ignored.

**Web UI not starting?**
```bash
docker compose logs webui
```
